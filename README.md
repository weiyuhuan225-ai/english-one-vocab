# 词见 · 考研英语一真题词汇筛查

275 个英语一真题词汇的静态学习网页，支持单词筛查、生词复习、词库检索、朗读及学习进度导入导出。

## 使用

打开 `index.html`，或通过 GitHub Pages 访问。所有页面样式、脚本和词库均包含在单个 HTML 文件中，无需安装依赖或构建。

学习进度保存在当前浏览器的本地存储中，不上传至服务器。更换浏览器或网站域名前，可在设置中导出 JSON 进度备份，再到新环境导入。

## GitHub Pages

在仓库 Settings → Pages 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/ (root)**，保存后等待部署完成。

当前仓库内的 `.nojekyll` 用于直接发布静态文件。
